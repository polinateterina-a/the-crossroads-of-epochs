# Перекрёсток эпох — интерактивная платформа исторических экскурсий

Аудиовизуальное путешествие по дореволюционному Красноярску через сопоставление исторических и современных фотографий с реконструированными звуковыми ландшафтами.

## О проекте

«Перекрёсток эпох» — это веб-приложение, которое позволяет пользователю пройти пешеходный маршрут из 4 исторических локаций. Для каждой локации доступны:

- историческое и современное фото (слайдер «Было/Стало»)
- реконструированный звуковой ландшафт (аудиоплеер)
- текстовое описание (200–300 слов)
- отображение на интерактивной карте с возможностью переключения между современным и дореволюционным слоем

**MVP реализован в полном объёме** — сайт является готовым продуктом.

---

## Функциональные возможности (MVP)

### Для пользователя
- Интерактивная карта (OpenStreetMap) с 4 маркерами локаций
- Переключение режима карты: «современный Красноярск» / «дореволюционный Красноярск»
- Поиск экскурсии по названию, описанию или тегам
- Краткая информация о локации по клику на маркер
- Модальное окно с полной информацией:
  - слайдер «Было/Стало»
  - аудиоплеер (воспроизведение/пауза/перемотка)
  - историческое описание
  - год постройки и теги
- Навигация по локациям (следующая / предыдущая)
- Автоостановка аудио при закрытии окна

### Для администратора
- Защищённая админ-панель
- Добавление и редактирование экскурсий
- Добавление и редактирование локаций
- Ручное размещение фото и аудио на сервере (в MVP)
